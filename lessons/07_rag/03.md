## Mental model
A retrieval improvement is a hypothesis to measure, not a universally better configuration. Query rewriting asks a real model for one concise search query while preserving identifiers, negations and intent. Generation still sees the original question. A rewrite that converts a specific serial-number request into a general warranty query may improve recall while destroying the task. Record both question and rewrite before evaluating.

Hybrid search fuses lexical and actual semantic rankings using reciprocal rank. It can keep exact identifier matches while broadening paraphrase coverage. It requires the same paid embedding consent as semantic search. Reranking instead retrieves a larger already-authorized candidate pool and asks a real model to rank supplied chunk IDs. The code checks returned membership and duplicates before selecting passages; the model cannot invent a new source or grant audience membership. Model ranking is nevertheless fallible and adds latency/cost.

The lab exposes --experiment rewrite or rerank and --strategy hybrid. Change only one compared variable: hold model, user, k and trial count fixed. For reranking, the defined change includes its larger candidate pool; do not attribute the outcome solely to a smarter ordering algorithm. The lab generation_trace reports generation usage only; additional rewrite/rerank calls are not silently claimed free. Use permitted tracing or instrument those calls for a full cost study.

Choose experiments using development cases. Freeze configuration before held-out review, then inspect per-case changes and possible regressions. The evaluator supports lexical versus semantic/hybrid strategy comparisons, while the lab supplies focused rewrite/rerank investigation. Neither repeatedly modifies prompts based on held-out grades.
