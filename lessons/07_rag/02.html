07.2 — Cite support, not just identifiers

Objective and prerequisites

course mission: Distinguish valid source membership from semantic support and choose deliberate abstention.

Prerequisite check: Lesson 01 and Module 03 semantic versus shape validation.

Sources and execution status

Installation is not execution evidence; consult verification. Local lexical/check paths need no credentials. Recall before reading

Can a true source ID accompany a false claim? Is an abstention with a citation consistent? Attempt both questions before consulting the mental model; compare your reasoning afterward rather than copying definitions.

Mental model

GroundedAnswer validates shape and internal consistency. A non-abstained answer must have source IDs, an abstention must not claim citations, and duplicates are rejected. validate_citations checks that each ID is present in retrieved trusted policy evidence. It does not check whether the cited passage entails the answer. The check lab deliberately supplies a clearly labelled human-authored 900-day return claim citing RETURN. Membership passes; a semantic reviewer should fail it against the current 30-day passage. This is a diagnostic counterexample, not an observed model response.

Review each substantive claim, not just the first number. The RETURN policy also requires unused items and a receipt, excludes final-sale items, and counts calendar days after delivery. SHIPPING uses business days after dispatch. A response can be numerically correct yet lose the condition that makes it useful. Quote the supporting phrase and identify the source revision. Do not use outdated text or untrusted instructions as evidence.

Empty evidence safely abstains in code. Nonempty irrelevant evidence, unresolved REMOTE/REMOTE-EXCEPTION conflict, and unsupported personal details require model abstention plus human evaluation. The prompt asks for that behavior; the application does not pretend a source-membership check proves it happened. Do not invent a precedence rule for the two current remote-work notices. A model may still fail, and the evaluator reports that failure rather than silently accepting plausible prose. Access denial also does not entitle the assistant to reveal what restricted documents contain.

Data/control flow

Typed proposal → source membership/trust check → claim-to-passage semantic review → supported answer or abstention

Worked example

Run from the repository root after uv sync --locked. This is implemented code/command guidance, not an observed output:

from langchain_learning.rag import GroundedAnswer, validate_citations
from langchain_learning.retrieval import PolicyIndex
proposal = GroundedAnswer(answer="Human-authored unsupported 900-day example",
                          source_ids=["RETURN"], abstained=False)
validate_citations(proposal, PolicyIndex().search("returns", "alice"))
# Passing here means membership only, not factual support.
