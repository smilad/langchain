# 13.2 — Connect using the current beta adapter

**In plain words:** You launch the local MCP server from Python with `MCPAdapter`. It turns the server's tools into LangChain tools that an agent can use. This API is in beta, so follow the current docs and not older examples.

**Mission/objective:** meet [the mission](../../MISSION.md) by launching the real local server through the current `MCPAdapter` API, then using the same adapted tools in a real agent.

**Prerequisites:** [MCP roles](01.md), async context managers, and `create_agent`. Check: explain why an awaited tool call differs from blocking Python I/O.

**Sources/version:** [MCP quickstart/transports](https://docs.langchain.com/oss/python/langchain/mcp) and [connections](https://docs.langchain.com/oss/python/langchain/mcp/connections), checked 2026-10-12. Python 3.14.0; LangChain 1.4.4 and FastMCP 4.1.0. The `langchain.mcp` namespace requires `langchain[mcp]>=1.4` and is beta; do not substitute older `langchain_mcp_adapters` examples. Actual run evidence belongs in [verification](../../docs/VERIFICATION.md).

## Worked connection
The lab's core API shape is:

```python
from pathlib import Path
from langchain.mcp import MCPAdapter

async with MCPAdapter(Path(server_script)) as adapter:
    tools = await adapter.list_tools()
    # Call a discovered tool, or pass tools to create_agent.
```

A `Path` means a local script launched over stdio. A string means an HTTP(S) URL; do not let untrusted configuration choose arbitrary executable paths. The course uses an absolute repository-owned path and its locked interpreter. The server imports the installed course package, so `uv sync --locked` is required before launching it outside the IDE.

The adapter's tools carry a client and are reentrant. Closing discovery does not permanently invalidate them: a later invocation can reconnect. The lab keeps the context open around its calls so one session spans discovery and execution.
