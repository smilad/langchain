13.2 — Connect using the current beta adapter

Mission/objective: meet the mission by launching the real local server through the current MCPAdapter API, then using the same adapted tools in a real agent.

Prerequisites: MCP roles, async context managers, and create_agent. Check: explain why an awaited tool call differs from blocking Python I/O.

Sources/version: MCP quickstart/transports and connections, checked 2026-10-12. Python 3.14.0; LangChain 1.4.4 and FastMCP 4.1.0. The langchain.mcp namespace requires langchain[mcp]>=1.4 and is beta; do not substitute older langchain_mcp_adapters examples. Actual run evidence belongs in verification.

Warm-up

What should survive tool-result serialization? What could a malicious tool description do? After attempting: retain typed data/provenance; descriptions can influence model selection but cannot be treated as an authorization policy.

Worked connection

The lab's core API shape is:

from pathlib import Path
from langchain.mcp import MCPAdapter

async with MCPAdapter(Path(server_script)) as adapter:
    tools = await adapter.list_tools()
    # Call a discovered tool, or pass tools to create_agent.

A Path means a local script launched over stdio. A string means an HTTP(S) URL; do not let untrusted configuration choose arbitrary executable paths. The course uses an absolute repository-owned path and its locked interpreter. The server imports the installed course package, so uv sync --locked is required before launching it outside the IDE.

The adapter's tools carry a client and are reentrant. Closing discovery does not permanently invalidate them: a later invocation can reconnect. The lab keeps the context open around its calls so one session spans discovery and execution.

Guided practice

Run uv run python labs/13_mcp/main.py --check, inspect tool names and actual artifacts, then predict the live agent's message sequence. With provider consent, run --live; it requires at least one actual MCP ToolMessage rather than labeling a plain model reply as integration proof. No generated answer is fabricated when credentials are absent.

Failure and independent variation

Replace a Path with a non-URL string in a private copy and identify the client-side configuration failure before changing prompts. Independently inspect quote behavior for sold-out stock using the exercise.

Exit and review

Explain how the server process, adapter context, and agent loop fit together. Distinguish a beta API warning from a broken call without suppressing it. Revisit imports against the API map during the capstone; use solutions only after recording an attempt.
