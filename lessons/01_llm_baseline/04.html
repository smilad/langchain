Mental model

A framework is an adapter and composition vocabulary, not an alternative source of truth. A provider SDK exposes that provider's response shape. LangChain supplies common messages, invocation methods, Runnable composition, tool schemas and agent orchestration. It does not own your business rubric, credentials policy, authorization or factual verification.

Worked choice and guided fading

For one small classification call, ordinary Python plus the provider SDK is a reasonable architecture. If your application needs reusable prompt/model/validation stages or a later tool loop, a standard interface can reduce wiring. Complete this design note: “I would keep the direct SDK here because ___; I would introduce LangChain when ___.” Cite a concrete requirement, not popularity.

Failure investigation and independent variation

Suppose swapping providers preserves invoke but rejects a content block or sampling parameter. Predict why common method names do not guarantee common capabilities. Inspect integration documentation before adjusting the design. In the exercise, inventory deterministic versus stochastic behavior and defend a minimal architecture.
