Mental model

Chunking changes the retrieval unit, not the underlying truth. A small chunk can isolate a number while losing its condition; a large chunk can dilute the signal with unrelated material and consume more generation context. Overlap keeps adjacent context at the cost of repeated text. The course uses a transparent character-window splitter with a preferred sentence boundary near the limit, not a tokenizer-aware claim of fitting every provider's context window. Its size and overlap are characters.

PolicyIndex accepts chunk_size and overlap. Each chunk copies source/version/audience/current/provenance/trust metadata and gains an ordinal chunk_id. content_sha256 identifies the full policy text; the corpus fingerprint identifies the complete source snapshot. Ordinal IDs are stable for an unchanged revision but can move when earlier text changes. That is why an edited source triggers complete replacement, not appending apparently new chunks beside old ones. A production publication workflow should advance version numbers; our temporary lab edit intentionally keeps the version to prove refresh detects bytes, not just revision labels.

The policies are short enough that defaults usually keep a source intact. Use a disposable long record to make chunking observable. Ask whether the warranty exclusion travels with the coverage statement. Never interpret repeated overlap as independent corroboration. Multiple chunks from RETURN still represent one source, not several witnesses. Answer citations use source IDs; the evidence report preserves chunk IDs so a reviewer can locate exact text.

Data/control flow

Source text → overlapping passage windows → copied metadata + ordinal ID → replacement snapshot

Worked example

Run from the repository root after uv sync --locked. This is implemented code/command guidance, not an observed output:

from langchain_learning.retrieval import chunk_text
text = "Warranty covers defects. " * 40
chunks = chunk_text(text, size=200, overlap=40)
print([(n, len(c)) for n, c in enumerate(chunks)])
