Mental model

Authorization is a candidate-selection rule, not a final response decoration. Public alice and bob may retrieve only public current sources. The finance identity additionally sees finance sources. An unknown identity raises PermissionError rather than receiving a broad default audience. In a service, trusted authentication maps a token to identity; the user or model must not choose an elevated identity. The retrieval function itself remains the execution boundary.

PolicyIndex checks the entire source snapshot before every query. It hashes filenames and bytes, validates a changed snapshot into a new document list, and only then swaps it in and clears semantic stores. Removed files therefore remove their chunks, and edits cannot leave old duplicates searchable. The approach is intentionally small-corpus and process-local: it rereads bytes, is not a concurrent ingestion service, and rebuilds remote embeddings after updates. A production index needs transactional update/serving boundaries and embedding-version provenance.

Hybrid retrieval is an explicit third strategy: reciprocal-rank fusion combines lexical and real semantic rankings after the same authorization filter. It changes one ranking mechanism but does not confer trust or resolve contradictory policies. Examine whether its candidate union improves the paraphrase while preserving SHIP-42. A bigger k may increase recall but adds irrelevant or malicious context. Keep k fixed when comparing strategies. Do not tune on the held-out set; choose the change on development questions and freeze it before final review.

Data/control flow

Caller identity → allowlisted audiences/current filter → ranking → top-k → evidence → generation

Worked example

Run from the repository root after uv sync --locked. This is implemented code/command guidance, not an observed output:

from langchain_learning.retrieval import PolicyIndex
index = PolicyIndex()
docs = index.search("finance reserve code", "alice", k=10)
assert all(d.metadata["audience"] == "public" for d in docs)
