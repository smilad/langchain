# 12.3 — Context contracts are executable boundaries

**In plain words:** A handoff between agents has three contracts: what the specialist may see, what its output must look like, and how many calls it gets. All three are checked in code.

**Mission/objective:** advance [the mission](../../MISSION.md) by rejecting an invalid specialist handoff and explaining why context ownership and termination belong in code.

**Prerequisites:** [specialist pattern](02.md), structured outputs, and filtered retrieval. Check: identify the difference between schema validity and authorized source membership.

**Sources/version:** [context engineering for subagents](https://docs.langchain.com/oss/python/langchain/multi-agent/subagents#context-engineering) and [call-limit middleware](https://docs.langchain.com/oss/python/langchain/middleware/built-in#model-call-limit), checked 2026-10-12. Installed baseline Python 3.14.0, LangChain 1.4.4, LangChain OpenAI 1.7.0; [uv.lock](../../uv.lock) defines exact dependencies and [verification](../../docs/VERIFICATION.md) separates local evidence from unavailable live proof. Real model capability and consent remain prerequisites.

## Recall
Who owns checkpoint state? Does another model inherit access because it received a question? After attempting: persistence belongs to the workflow/checkpointer; a question contains no authority.

## Mental model
A handoff has three separate contracts: input scope, output meaning, and execution budget. The application fixes `user_id` and retrieved documents. The specialist receives only the question; it cannot query a broader identity. Its output has `answer`, `source_ids`, and `abstained`. Membership validation rejects citations outside the selected evidence. A non-abstaining answer requires citations, while an abstention must not imply supporting sources.

These checks do **not** prove every cited claim is supported. Semantic review remains a separate gate. Also, a source can contain malicious instructions; retaining provenance is useful but does not make its prose trusted instructions.

## Worked boundary
`validate_handoff(proposal, permitted_ids)` runs both after the specialist and after the coordinator. Model-call middleware permits four drafter calls; the coordinator gets three. Tool-call limits allow two retrieval calls and one delegation. Graph recursion is separately capped at twelve per agent. Provider SDK retries can add physical network requests, so logical-call budgets are not a precise bill.

Run `uv run python labs/12_multi_agent/main.py --live --trials 1 --fail-specialist`. After a real specialist generates a result, the lab deliberately replaces its citations with `not-retrieved`. This is a labeled boundary fault injection, **not** evidence that the model naturally produced that error. The validator stops propagation; no automatic fallback drafts a replacement.
